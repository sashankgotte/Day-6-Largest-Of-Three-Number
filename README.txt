# Day 6 - Largest of Three Numbers

## 📌 Description
This Python program finds the largest among three numbers entered by the user using Python's built-in `max()` function.

## 🎯 Objective
- Learn how to take three numbers as input.
- Understand the `max()` function in Python.
- Improve logical thinking and programming skills.

## 💻 Program
```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

print("Largest =", max(a, b, c))
```

## ▶️ Sample Output
```text
Enter first number: 10
Enter second number: 25
Enter third number: 15
Largest = 25
```
